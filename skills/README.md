# FDEOps skills

Use any task folder directly, or use `fde` to coordinate a customer project. Each folder's `SKILL.md` explains when to use it and which inputs it needs.

The [complete catalog](https://github.com/suboss87/FDEOps/blob/Main/docs/skills-reference.md) groups every installable skill by the work it supports. Start with the [README](../README.md) for installation and examples.

For contributors: instructions are authored once under `fde/references/`. Task folders are generated from those instructions and `bin/skill-catalog.js`; run `npm run generate:skills` after changes. Keep private customer records outside this repository.
